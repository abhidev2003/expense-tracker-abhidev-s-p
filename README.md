# Expense Tracker

A responsive personal expense tracker built using HTML, CSS, and JavaScript.

## Features

- Add income and expense transactions
- Edit and delete transactions
- Add and manage categories
- Track total income, expenses, and balance
- Set and track a budget
- Filter transactions by type and category
- View daily, weekly, monthly, and yearly summaries
- Store data using browser Local Storage
- Export transaction data as JSON
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Font Awesome
